# Môi trường demo hiện có

Sau reset ngày 15/11/2026, các database demo/restore cũ đã được xóa. Các lệnh demo bên dưới chỉ mô tả cấu hình trước đây, chưa chạy lại được; chưa tạo demo hoặc nạp seed thay thế.

Bộ demo trước V2 dùng backend npm run demo và frontend npm run demo, mở http://127.0.0.1:5175. Đây là dữ liệu của mô hình cũ, chưa đại diện thiết kế mới.

Chưa tạo bộ demo V2. Không seed/reset hay phục hồi database chỉ để đồng bộ tài liệu. Giữ cấu hình .env, backup và kho minh chứng đang có.

Xem [thiết kế V2](requirements/PERSONAL_VAULT_V2.md), [cài đặt](deployment/GETTING_STARTED.md) và [backup/restore](deployment/RUNBOOK_DEMO_BACKUP_RESTORE.md).
