API RAG thêm metadata trả về: citations[].versionId, citations[].sourceUrl (nullable), providerError=PROVIDER_UNAVAILABLE khi dự phòng. isSufficientData=false và citations=[] khi thiếu nguồn/citation sai; explanationText không hiển thị câu trả lời không kiểm chứng. DB không thêm bảng/cột: dùng JSON citations và is_sufficient_data hiện có. URL chỉ mở HTTP(S); URL metadata chưa bảo đảm đúng nội dung phiên bản, phải đối chiếu tài liệu gốc trước nghiệm thu.
