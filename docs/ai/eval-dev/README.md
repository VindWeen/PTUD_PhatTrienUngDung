# Dữ liệu đánh giá AI phiên bản trước

Các file JSON trong thư mục này là dữ liệu tổng hợp và nhãn kỹ thuật của phiên bản trước. Giữ để đối chiếu và phục vụ công cụ hiện có; không dùng làm yêu cầu nghiệp vụ V2 hoặc quy chế thực tế.

Các tham chiếu đến tài liệu bàn giao cũ trong corpus có thể không còn tồn tại sau đợt dọn Markdown. Chưa tái tạo corpus hoặc chạy lại benchmark trong đợt này.
